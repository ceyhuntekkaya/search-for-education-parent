
1. Bulk slot oluşturma — POST /api/appointments/slots/bulk
Request (AppointmentSlotBulkCreateDto) — yeni alanlar:

{
  "schoolId": 38,
  "staffUserIds": [108, 109],
  "appointmentTypes": ["PARENT_MEETING", "INFORMATION_MEETING"],
  "selectedDates": ["2026-06-08"],
  "selectedTimeSlots": ["09:00-09:30", "09:30-10:00"],
  "skipExisting": true,
  "failFast": false
}
staffUserIds ve appointmentTypes artık dizi; eski tekil staffUserId / appointmentType hâlâ çalışır.
Kombinasyon: her personel × her tip × her tarih × her saat.
Response (AppointmentSlotBulkCreateResultDto) — mutlaka kontrol et:

{
  "totalRequested": 14,
  "createdCount": 14,
  "skippedCount": 0,
  "errorCount": 0,
  "skipped": null,
  "createdSlots": [...]
}
success: true tek başına yeterli değil; createdCount / skippedCount / skipped listesine bak.

5. Veli takip sonucu — POST /api/appointments/bulk (madde 7)
Yeni enum — ParentFollowUpOutcome:

ENROLLED              // Kayıt oldu
TO_FOLLOW_UP          // Takip edilecek
APPOINTMENT_POSTPONED // Randevu erteleme
WAITING_FOR_INFO      // Bilgi bekliyor
WONT_FOLLOW_UP        // Takip edilmeyecek
DID_NOT_ATTEND        // Görüşmeye gelmedi
BulkAppointmentOperationDto — yeni alanlar:

parentFollowUpOutcome?: ParentFollowUpOutcome
followUpRequired?: boolean
followUpDate?: string        // "2026-06-15"
followUpTime?: string        // "14:30"
outcomeNotes?: string
noSaleReason?: string
// mevcut alanlar: operation, appointmentIds, newStatus, customMessage, notifyParticipants...
Zorunlu alan kuralları (frontend validasyonu):

Sonuç	Zorunlu alanlar	newStatus
ENROLLED
—
COMPLETED (varsayılan)
TO_FOLLOW_UP
followUpDate, followUpTime, outcomeNotes, noSaleReason
COMPLETED
APPOINTMENT_POSTPONED
followUpDate, followUpTime, outcomeNotes
COMPLETED
WAITING_FOR_INFO
followUpDate, followUpTime, outcomeNotes
COMPLETED
WONT_FOLLOW_UP
noSaleReason
COMPLETED
DID_NOT_ATTEND
followUpDate, followUpTime, outcomeNotes
NO_SHOW (zorunlu)
parentFollowUpOutcome yalnızca operation: "UPDATE_STATUS" ile kullanılır.
Response DTO'larda yeni alanlar (AppointmentDto, AppointmentSummaryDto):

followUpTime
parentFollowUpOutcome
noSaleReason
outcomeNotes        // summary'de de var
Örnek — Takip edilecek:

{
  "operation": "UPDATE_STATUS",
  "appointmentIds": [27],
  "newStatus": "COMPLETED",
  "parentFollowUpOutcome": "TO_FOLLOW_UP",
  "followUpDate": "2026-06-15",
  "followUpTime": "14:30",
  "outcomeNotes": "Veli tekrar aranacak",
  "noSaleReason": "Fiyat Pahalı"
}
